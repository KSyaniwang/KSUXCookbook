How to use the Figma library

Use these steps to build with the shared brand foundations instead of recreating assets from scratch.

01

Add components

  1. Open Assets in Figma’s left sidebar and click the small Library book icon.
  2. Open Manage libraries, go to Teams, then hover over Component Library and click Add to file. Repeat this for Tokens.
  3. In any design file, return to Assets and open the Component Library.
  4. Open Buttons and start with Visual btn, or browse the library for another component.
02

Change color

  1. Select the layer you want to update.
  2. In the right sidebar, find Fill and open the library selector.
  3. Choose a color from Tokens, or search for the token you need.
  4. Use the gradient tokens when the design calls for a gradient.
03

Apply typography

  1. Select the text layer you want to format.
  2. In the right sidebar, open the shared style selector under Typography.
  3. Choose the style by purpose: headings for titles, body styles for reading, and captions for labels.
